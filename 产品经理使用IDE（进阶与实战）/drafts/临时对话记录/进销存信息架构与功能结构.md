# 3C电子产品进销存系统 - 信息架构与功能结构

> **基于文档**：进销存功能清单.md  
> **适用场景**：小型3C电子产品商家（零售+批发）  
> **创建日期**：2026-01-31

---

## 📐 系统信息架构总览

```
进销存系统
├── 首页（工作台）
├── 商品中心
├── 采购中心
├── 销售中心
├── 库存中心
├── 客户中心
├── 供应商中心
├── 财务中心
├── 报表中心
├── 序列号中心
└── 系统设置
```

---

## 1️⃣ 首页（工作台）

### 页面结构

```
首页/工作台
├── 快捷入口区
├── 数据概览区
├── 待办事项区
└── 经营分析区
```

### 页面功能

| 功能区域     | 功能说明                                     |
| ------------ | -------------------------------------------- |
| **快捷入口** | 销售开单、采购入库、库存盘点、收款、付款     |
| **数据概览** | 今日销售额、今日利润、库存总额、应收应付     |
| **待办事项** | 待审核单据、库存预警、待收款提醒、待付款提醒 |
| **经营分析** | 销售趋势图、热销商品TOP10、库存周转率        |

### 页面操作

- **快捷跳转**：点击快捷入口直接进入对应功能页面
- **刷新数据**：刷新实时数据

### 2.1 商品列表

#### 页面布局

```
商品列表页
├── 筛选区（商品编码、名称、分类、品牌）
├── 操作按钮区（新增商品、批量导入、批量导出）
├── 数据表格区
└── 分页区
```

#### 表格列

| 列名           | 说明                         |
| -------------- | ---------------------------- |
| 商品编码       | 系统生成或手动输入           |
| 商品名称       | 如：iPhone 15 Pro 256GB 黑色 |
| 分类           | 手机/平板/电脑/配件          |
| 品牌           | Apple/华为/小米              |
| 规格型号       | 256GB/黑色                   |
| 成本价         | ¥5,000.00                    |
| 零售价         | ¥6,999.00                    |
| 批发价         | ¥6,500.00                    |
| 库存数量       | 50                           |
| 是否序列号管理 | 是/否                        |
| 状态           | 在售/停售                    |
| 操作           | 查看、编辑、删除             |

#### 页面操作

| 操作          | 说明                                 | 权限要求      |
| ------------- | ------------------------------------ | ------------- |
| **新增商品**  | 打开新增表单，填写商品信息           | 管理员/仓管员 |
| **编辑商品**  | 修改商品信息（价格、库存预警等）     | 管理员/仓管员 |
| **删除商品**  | 删除商品（需检查是否有库存）         | 管理员        |
| **查看详情**  | 查看商品详细信息、库存明细、销售记录 | 所有角色      |
| **批量导入**  | Excel导入商品数据                    | 管理员        |
| **批量导出**  | 导出商品列表到Excel                  | 管理员/仓管员 |
| **筛选查询**  | 按条件筛选商品                       | 所有角色      |
| **启用/停售** | 切换商品状态                         | 管理员        |
