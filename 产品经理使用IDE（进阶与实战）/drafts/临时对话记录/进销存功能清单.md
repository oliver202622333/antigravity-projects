# 3C电子产品进销存系统功能清单（简化版）

> **适用场景**：3C电子产品小微商家（≤10人，单店或2-3门店）  
> **业务特点**：零售+批发，强调快速、简单、易用  
> **设计原则**：高频功能极致优化，低频功能可选支持  
> **版本说明**：简化版（适合快速上手），标准版功能见备注  
> **创建日期**：2026-01-31

---

## 📋 功能模块总览

| 模块       | 核心功能                       | 优先级 | 说明             |
| ---------- | ------------------------------ | ------ | ---------------- |
| 商品管理   | 商品档案、分类、品牌、库存查询 | P0     | 核心基础数据     |
| 采购管理   | 采购入库                       | P0     | 简化版无采购订单 |
| 销售管理   | 销售订单                       | P0     | 开单即扣库存     |
| 库存管理   | 库存查询、盘点                 | P0     | 简化版单店无调拨 |
| 客户管理   | 客户档案、欠款管理             | P1     | 批发业务必需     |
| 供应商管理 | 供应商档案、往来账             | P1     | -                |
| 财务管理   | 收款、付款                     | P1     | 核心收付款       |

## 1️⃣ 商品管理

### 1.1 商品档案

- **商品基础信息**
  - 商品编码（支持自定义或自动生成）
  - 商品名称（如：iPhone 15 Pro 256GB 黑色）
  - 商品分类（手机/平板/电脑/配件等）
  - 品牌（从品牌库选择）
  - 型号/规格
  - 计量单位（从单位库选择）
  - 成本价、零售价、批发价
  - 商品图片
  - 商品属性（颜色、内存、版本等，从属性库选择）
  - 备注

- **是否管理序列号**
  - 是（手机、平板、笔记本等高价值商品）
  - 否（充电器、数据线等低价值配件）

- **库存预警**
  - 最低库存预警
  - 最高库存预警

### 1.2 商品分类

- 分类管理（支持二级分类）
  - 手机
  - 平板
  - 电脑（笔记本/台式机）
  - 配件（充电器/数据线/耳机/保护壳等）
  - 智能设备（手表/手环等）

### 1.3 商品品牌

- **品牌档案**
  - 品牌编码
  - 品牌名称（Apple、华为、小米、OPPO、vivo等）
  - 品牌logo
  - 品牌说明
  - 排序

- **品牌管理**
  - 新增品牌
  - 编辑品牌
  - 删除品牌（需检查是否有商品使用）
  - 启用/停用

### 1.4 计量单位

- **单位档案**
  - 单位编码
  - 单位名称（台、个、套、箱、件等）
  - 单位说明

- **单位管理**
  - 新增单位
  - 编辑单位
  - 删除单位（需检查是否有商品使用）

### 1.5 商品属性

- **属性定义**
  - 属性名称（如：颜色、内存、版本）
  - 属性值（如：颜色属性的值：黑色、白色、金色）
  - 适用分类（该属性适用于哪些商品分类）

- **属性管理**
  - 新增属性
  - 编辑属性
  - 删除属性
  - 为属性添加/删除属性值

- **应用场景**
  - iPhone 15 Pro：
    - 颜色属性：黑色、白色、蓝色、自然钛色
    - 内存属性：128GB、256GB、512GB、1TB
    - 版本属性：国行、港版、美版
  - 通过属性组合生成不同的SKU

### 1.6 库存查询

- 实时库存查询
- 按商品、分类、品牌查询
- 库存预警提示
- 序列号库存查询（显示每个序列号的状态）

### 2.1 采购入库（P0核心）

### 2.1 采购订单

  - 订单总额
  - 预计到货日期
  - 备注

- **订单状态管理**
  - 待入库
  - 部分入库
  - 已完成
  - 已取消

  - 待审核

## 3️⃣ 销售管理

> **简化版设计**：销售订单直接扣减库存，无需出库单  
> **核心诉求**：快速开单，3-5秒完成一单  
> **适用场景**：零售（即买即走）和批发（开单后发货）

### 3.1 销售订单（P0核心）

**快速开单功能**（高频，必须极致优化）

- 选择客户（零售客户可选"散客"）
- 扫码/搜索添加商品
- 选择序列号（针对序列号商品）
- 数量、单价（支持零售价/批发价切换）
- 优惠/折扣
- 收款方式（现金/微信/支付宝/银行卡/欠款）
- 打印小票

- **销售类型**
  - 零售（散客，小额，即时收款）
  - 批发（客户，大额，可欠款）

- **订单状态**
  - 待出库
  - 部分出库
  - 已完成
  - 已取消

### 3.2 销售出库

- **创建出库单**
  - 关联销售订单（或直接出库）
  - 出库商品明细
  - 序列号选择（针对需要序列号的商品）
  - 实际出库数量
  - 出库仓库/门店

- **出库单审核**
  - 待审核
  - 已审核（扣减库存）

### 3.3 销售退货

- 退货申请
- 退货入库
- 退款处理
- 增加库存

### 3.4 预订单（可选，P2）

- 预订单管理
- 订金/预付款
- 到货通知

## 💡 3C电子产品行业特点

### 商品特点

- **SKU多样**：同一款手机有不同颜色、容量，需要精细化管理
- **价格变化快**：需要灵活调价
- **序列号管理**：手机、平板等高价值商品需要序列号管理
- **保修期管理**：3C产品有保修期，需要记录保修到期时间

### 业务特点

- **零售+批发**：需要支持散客零售和批发客户
- **价格体系**：零售价、批发价需要明确区分
- **快速开单**：零售场景需要快速开单收款
- **欠款管理**：批发客户常有欠款，需要往来账管理

### 库存特点

- **周转快**：热门商品周转快，需要及时补货
- **呆滞风险**：冷门商品或过时型号容易积压
- **序列号追溯**：出现质量问题需要追溯批次
