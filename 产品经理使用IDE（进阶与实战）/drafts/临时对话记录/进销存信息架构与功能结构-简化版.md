# 3C电子产品进销存系统 - 信息架构与功能结构（简化版）

> **基于文档**：进销存功能清单-简化版.md  
> **适用场景**：3C电子产品小微商家（≤10人，单店或2-3门店）  
> **设计原则**：高频必用，低频可选，简单易懂  
> **版本**：简化版 V1.0  
> **创建日期**：2026-01-31

---

## 📐 系统信息架构总览

```
进销存系统（简化版）
├── 首页（Dashboard）
├── 商品中心（含序列号管理）
├── 采购中心
├── 销售中心
├── 库存中心
├── 财务中心
├── 报表中心
├── 基础资料（客户、供应商）
└── 系统设置
```

> **简化说明**：相比标准版减少3个一级菜单，将相关功能合并，使结构更简洁

---

## 1️⃣ 首页（Dashboard）

### 页面结构

```
首页/Dashboard
├── 快捷入口区
├── 数据概览区（今日）
├── 提醒事项区
└── 经营分析区
```

### 页面功能

| 功能区域     | 功能说明                                                                           |
| ------------ | ---------------------------------------------------------------------------------- |
| **快捷入口** | 销售开单、采购入库、库存查询、收款                                                 |
| **今日数据** | 今日销售额、今日利润、今日单数、今日收款                                           |
| **提醒事项** | ⚠️ 库存预警（N个商品不足）<br>⚠️ 欠款提醒（N个客户逾期）<br>⚠️ 即将过保（N个商品） |
| **经营分析** | 7天销售趋势图、热销商品TOP5、库存金额                                              |

### 页面操作

- **快捷跳转**：点击快捷入口/提醒事项直接进入对应页面
- **刷新数据**：手动刷新或自动刷新
