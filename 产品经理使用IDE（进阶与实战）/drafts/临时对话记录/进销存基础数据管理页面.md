### 2.4 商品品牌管理

#### 页面布局
```
商品品牌列表页
├── 操作按钮区（新增品牌）
├── 数据表格区
```

#### 表格列
| 列名 | 说明 |

| 操作 | 说明 |
|------|------|

| **删除品牌** | 删除品牌（需检查是否有商品使用） |

### 2.6 商品属性管理

#### 页面布局

```
商品属性管理页
├── 属性列表（左侧）
│   ├── 颜色
│   ├── 内存
│   ├── 版本
│   └── ...
└── 属性值管理（右侧）
    ├── 属性值列表
    └── 新增/编辑/删除属性值
```

#### 属性列表（左侧表格）

| 列名       | 说明                      |
| ---------- | ------------------------- |
| 属性名称   | 颜色                      |
| 适用分类   | 手机、平板                |
| 属性值数量 | 5个（黑色、白色、金色等） |
| 操作       | 编辑、删除、管理属性值    |

#### 属性值列表（右侧）

选中"颜色"属性后，右侧显示属性值：
| 属性值 | 排序 | 操作 |
|--------|------|------|
| 黑色 | 1 | 编辑、删除 |
| 白色 | 2 | 编辑、删除 |
| 金色 | 3 | 编辑、删除 |
| 蓝色 | 4 | 编辑、删除 |
| 自然钛色 | 5 | 编辑、删除 |

#### 页面操作

| 操作           | 说明                               |
| -------------- | ---------------------------------- |
| **新增属性**   | 创建新的属性类型（如：网络制式）   |
| **编辑属性**   | 修改属性名称、适用分类             |
| **删除属性**   | 删除属性（需检查是否有商品使用）   |
| **新增属性值** | 为选中的属性添加新的属性值         |
| **编辑属性值** | 修改属性值名称                     |
| **删除属性值** | 删除属性值（需检查是否有商品使用） |
| **排序**       | 调整属性值显示顺序                 |

#### 3C产品常用属性

- **颜色**：黑色、白色、金色、蓝色、紫色、绿色等
- **内存**：64GB、128GB、256GB、512GB、1TB
- **版本**：国行、港版、美版、日版
- **运行内存**：6GB、8GB、12GB、16GB
- **网络制式**：5G、4G
- **屏幕尺寸**：6.1英寸、6.7英寸

#### 商品SKU生成

通过属性组合生成SKU：

```
iPhone 15 Pro + 256GB + 黑色 + 国行 = SKU001
iPhone 15 Pro + 256GB + 白色 + 国行 = SKU002
iPhone 15 Pro + 512GB + 黑色 + 国行 = SKU003
...
```
