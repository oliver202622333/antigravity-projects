# Role

你是一位资深的前端开发工程师，精通 HTML5, CSS3 以及复杂桌面级 Web 应用（如 Web IDE、金融终端）的 UI 布局还原。

# Task

请仔细观察我上传的这张复杂软件界面截图，使用原生的 HTML 和 CSS （可附带少量原生 JavaScript 用于实现基础的折叠/切换效果），高保真还原该界面的整体布局和视觉风格。

# UI Layout Requirements

请使用 CSS Flexbox 或 Grid 现代布局技术，将页面划分为以下几个核心区域：

1. **整体框架**：采用经典 IDE 的全屏响应式布局，支持各个面板的区域划分。
2. **左侧边栏 (Left Sidebar)**：
   - 垂直方向分为上下两部分。
   - 内部为树状目录结构（Tree View），包含文件夹和文件的层级缩进、图标占位符及辅助文本（如右侧的代码/编号）。
3. **主工作区 (Main Content)**：
   - **顶部**：多标签页（Tabs）导航栏及下方的一排工具栏（包含各种操作图标按钮的占位）。
   - **中上部核心区**：一个支持层级展开的复杂数据表格（Tree-Grid），包含表头（条件、行号、条件分支等）以及带有连接线缩进的逻辑树状数据。
   - **中下部面板**：一个常规的属性数据表格，包含序号、字段属性、字段名称、数据类型等列。
4. **底部控制台 (Bottom Panel)**：
   - 日志输出控制台（Console Log），显示多行带时间戳的运行日志文本。

# Styling & Theme Constraints

1. **暗黑主题 (Dark Mode)**：准确提取图片中的核心色调。背景色以深灰/深蓝灰为主，边框线采用更深的暗色或细微的亮色做分割。
2. **排版与字体**：使用紧凑的系统级无衬线字体（如 Segoe UI, Microsoft YaHei），字号偏小（12px - 14px），以适应密集型数据展示。
3. **文本颜色**：默认文本使用浅灰/白色，针对特定高亮（如选中的行、特定的日志级别 [Info]、特定的条件节点）使用图片中对应的绿色、蓝色或黄色进行着色。
4. **边框与阴影**：面板之间需要有清晰但低调的 1px 分割线，体现出窗口嵌套的质感。

# Output Format

1. 请输出一个完整的、可直接在浏览器中运行的 `.html` 文件代码。
2. **将所有的 CSS 和 JavaScript 直接内联在 `<style>` 和 `<script>` 标签中，不要拆分多文件。**
3. 对于图片中模糊不清的具体文本或图标，请使用**符合量化交易配置、数据表同步或系统日志场景**的合理中英文占位符（例如：IC2602, 行情数据, 触发条件等）进行填充。
4. “请优先搭好整体的分栏框架（HTML+CSS），表格和树状图内部可仅用少量示例数据填充，重点保证布局的完美自适应。”
