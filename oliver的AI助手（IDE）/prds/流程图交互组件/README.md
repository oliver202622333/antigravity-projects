## 功能概述

本模块解决流程图泳道列宽拖拽时，连接线不跟随节点移动的问题。

### 核心功能

| 功能 | 说明 | 优先级 |
|-----|------|-------|
| 垂直泳道列宽拖拽 | 拖拽泳道边框时连接线实时跟随 | P0 |
| 水平泳道行高拖拽 | 拖拽泳道边框时连接线实时跟随 | P0 |
| 单节点拖拽 | 拖拽节点时连接线实时跟随 | P0 |
| 多节点拖拽 | 框选拖拽时连接线实时跟随 | P1 |
| 撤销/重做 | 支持拖拽操作的撤销重做 | P1 |
