## 功能概述

实现类似Excel的拆分窗口功能，支持将工作表拆分为多个可独立滚动的窗格，方便同时查看和编辑表格的不同区域。

### 核心功能

| 功能 | 说明 | 优先级 |
|-----|------|-------|
| 水平拆分 | 拆分为上下两个窗格 | P0 |
| 垂直拆分 | 拆分为左右两个窗格 | P0 |
| 四宫格拆分 | 同时水平+垂直拆分，4个窗格 | P0 |
| 拆分条拖拽 | 拖拽调整拆分位置 | P0 |
| 取消拆分 | 双击或菜单取消 | P0 |
| 独立滚动 | 各窗格可独立滚动 | P0 |
| 数据同步 | 任一窗格编辑，其他同步更新 | P0 |

### 操作方式

- **拖拽拆分**：拖拽滚动条端点的拆分条
- **菜单操作**：视图菜单 → 拆分/取消拆分
- **快捷键**：Alt+W,S（Windows）/ ⌥+W,S（Mac）
