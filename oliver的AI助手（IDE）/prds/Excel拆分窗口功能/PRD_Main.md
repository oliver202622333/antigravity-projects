| 术语 | 定义 | 备注 |

## 1. 项目概述

### 1.1 背景与现状（Why）

**现状描述**：
- 当前表格组件仅支持单窗口视图，用户在处理大型表格时，无法同时查看和对比不同区域的数据
- 用户需要频繁上下左右滚动来参照不同区域的数据，操作效率低
- 缺少类似Excel的拆分窗口功能，无法满足复杂数据处理场景

**关键痛点**：
1. **数据对比困难**：无法同时查看表格的不同区域，核对数据需反复滚动
2. **操作效率低**：跨区域数据录入/核对时，频繁滚动导致效率低下
3. **用户体验差**：与用户习惯的Excel操作不一致，学习成本高

**影响**：
- **效率损失**：大型表格数据处理时间增加约30%
- **用户满意度**：用户反馈表格功能不完善，影响整体产品体验
- **场景受限**：无法支持财务报表、数据分析等专业场景

### 1.2 目标与价值（What / Value）

**业务目标（可量化）**：
- 支持10万行×100列表格流畅拆分操作
- 用户数据对比效率提升50%
- 与Excel操作习惯一致性≥95%

**用户目标**：
- **财务人员**：同时查看表头和数据区域，快速对账
- **数据分析师**：同时对比不同区域数据，发现关联
- **数据录入员**：参照表头信息，快速录入数据

**系统目标**：
- 实现水平、垂直、四宫格三种拆分模式
- 各窗格独立滚动，数据同步更新
- 支持拆分条拖拽、菜单、快捷键三种操作

### 1.3 成功指标与口径
| 指标 | 定义/计算口径 | 数据来源 | 统计周期 | 目标值 |
|---|---|---|---|---|
| 功能使用率 | 使用拆分窗口功能的用户占比 | 埋点数据 | 月度 | ≥20% |
| 操作成功率 | 成功使用拆分窗口功能的次数占尝试次数比例 | 埋点数据 | 月度 | ≥98% |
| 用户满意度 | 用户对该功能的满意度评分 | 用户调研 | 季度 | ≥4.3/5.0 |
| 性能帧率 | 拆分/滚动操作时页面帧率 | 性能监控 | 每次操作 | ≥30fps |

### 1.4 范围边界（Scope）

**In Scope**
- 水平拆分（上下两个窗格）
- 垂直拆分（左右两个窗格）
- 四宫格拆分（同时水平+垂直，4个窗格）
- 拆分条拖拽调整拆分位置
- 菜单命令拆分/取消拆分
- 快捷键支持
- 各窗格独立滚动
- 数据在所有窗格同步更新
- 活动窗格标识

**Out of Scope**
- 冻结窗格功能（独立功能）
- 多窗口（打开多个文件窗口，独立功能）
- 窗格独立缩放（所有窗格保持一致缩放比例）

**约束条件**
- **技术约束**：基于现有表格组件架构实现
- **性能约束**：支持10万行×100列表格流畅操作
- **兼容性约束**：支持Chrome、Firefox、Safari、Edge主流浏览器
- **兼容性约束**：与Excel操作习惯保持一致

## 3. 业务规则

| 规则编号 | 规则描述 | 适用场景 |
| -------- | -------- | -------- |
| R01 | 拆分位置限制在单元格边界 | 所有拆分场景 |
| R02 | 数据完全同步 | 数据编辑场景 |
| R03 | 滚动独立不重叠 | 四宫格拆分场景 |

### R01：拆分位置规则

- **规则描述**：拆分条只能在单元格边界进行拆分，窗口边界对齐单元格
- **适用场景**：所有拆分、调整拆分位置
- **处理逻辑**：
  1. 拖拽拆分条时，吸附到最近的单元格边界
  2. 拆分位置与单元格边界对齐
  3. 确保单元格不被分割显示
- **示例**：拖拽到行高50%位置时，对齐到第N行和N+1行之间

### R02：数据同步规则

- **规则描述**：任一窗格中修改、格式、公式修改，其他窗格立即同步显示
- **适用场景**：数据编辑
- **处理逻辑**：
  1. 任一窗格的单元格修改操作
  2. 底层数据模型更新
  3. 所有窗格的渲染同步重新渲染
  4. 保持各窗格的滚动位置不变
- **示例**：左上窗格修改A1单元格内容，其他三个窗格的A1单元格同步更新

### R03：窗格滚动规则

- **规则描述**：四宫格拆分时，相邻窗格共享滚动
- **适用场景**：四宫格拆分
- **处理逻辑**：
  1. 左上窗格垂直滚动 → 左下窗格同步垂直滚动
  2. 左上窗格水平滚动 → 右上窗格同步水平滚动
  3. 右上窗格垂直滚动 → 右下窗格同步垂直滚动
  4. 左下窗格水平滚动 → 右下窗格同步水平滚动
- **示例**：左下窗格向下滚动10行，左上窗格也向下滚动10行；右上窗格不动

## 4. 页面与交互

详细的页面原型、交互流程和UI说明见 [附件A: 页面与交互说明](./附件A_页面与交互说明.md)

### 4.1 交互概要

| 交互名称 | 触发方式 | 交互描述 |
|---------|---------|---------|
| 水平拆分 | 拖拽垂直滚动条顶部拆分条 | 拖拽到目标位置释放，拆分为上下窗格 |
| 垂直拆分 | 拖拽水平滚动条右侧拆分条 | 拖拽到目标位置释放，拆分为左右窗格 |
| 调整拆分 | 拖拽已有的拆分条 | 实时调整拆分位置 |
| 取消拆分 | 双击拆分条 / 菜单命令 / 快捷键 | 恢复单窗口视图 |

## 5. 异常处理

| 异常场景 | 触发条件 | 处理规则 | 提示信息 |
|---------|---------|---------|---------|
| 表格过小 | 表格行数<2或列数<2 | 禁用拆分功能 | "表格太小，无法拆分" |
| 性能卡顿 | 数据量>100万单元格 | 使用虚拟滚动优化 | 无提示 |
| 数据冲突 | 同时编辑冲突 | 以最后编辑为准，提示用户 | "数据已更新" |

## 6. 非功能性需求

### 6.1 性能要求
- 拆分操作响应延迟<100ms
- 支持10万行×100列表格流畅滚动
- 内存占用≤500MB（10万行数据）
- 滚动帧率≥30fps

### 6.2 兼容性要求
- 支持Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- 支持PC端鼠标操作
- 支持触屏（平板/手机）

### 6.3 可用性要求
- 拆分条可识别区域≥8px
- 拖拽过程中提供视觉反馈
- 支持ESC键取消当前拖拽
- 操作习惯与Excel保持一致

### 6.4 Excel兼容性
| 操作 | Excel行为 | 本产品行为 |
|-----|-----------|-----------|
| 水平拆分 | 拖拽右上角拆分条 | 一致 |
| 垂直拆分 | 拖拽右下角拆分条 | 一致 |
| 取消拆分 | 双击拆分条 | 一致 |
| 快捷键 | Alt+W,S（拆分） | 一致 |
