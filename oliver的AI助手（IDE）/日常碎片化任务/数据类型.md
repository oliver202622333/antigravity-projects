# 前端与后端数据类型对比表（量化场景）

> **文档说明**：整理前后端开发中常见的数据类型对比、作用及量化场景示例，辅助产品经理与开发沟通。

---

## 一、基础类型对比

| 后端类型 | 前端类型 | 作用 | 数据库对应 | 量化场景示例 |
|---------|---------|------|-----------|-------------|
| **bool** | boolean | 表示是/否两种状态 | BOOLEAN / TINYINT(1) | 是否停牌、是否允许交易 |
| **int / int32_t** | number | 存储普通整数 | INT | 数量（100股）、状态码(0=正常,1=异常) |
| **int64_t / long** | number / string | 存储超大整数（时间戳、大额） | BIGINT | 时间戳(1715666666666)、成交额、总股本 |
| **float / double** | number | 存储带小数的数值 | FLOAT / DOUBLE | 股价(10.55)、收益率(0.03)、因子值 |
| **std::string** | string | 存储变长文字 | VARCHAR / TEXT | 股票代码("SHSE.600000")、股票名 |
| **char[N]** | string | 存储固定长度文字 | CHAR(N) | 交易所编码、固定格式代码 |

## 八、前后端数据传输注意事项

### 1. 精度问题
- **后端double** → **前端number**：可能丢失精度
- **大整数（时间戳）**：前端建议用 `string` 或 `BigInt`
- **股价计算**：建议后端做计算，前端只展示

### 2. 类型映射
| 后端 → 前端 | 注意事项 |
|------------|---------|
| int64_t | 前端JS number最大只能到2^53-1，超范围用string |
| enum | 前端建议用枚举对象或常量 |
| vector | 对应数组 `[]` |
| map | 对应对象 `{}` 或 `Map` |

### 3. JSON序列化
- 前后端通常通过JSON传输
- 数组用 `[]`，对象用 `{}`
- 布尔值用 `true/false`，不是字符串

## 九、常用格式示例

### 后端C++ → JSON示例
```json
{
  "tradeDay": "2025-10-16",
  "stockCode": "SHSE.600000",
  "price": 10.55,
  "volume": 1000,
  "isTrading": true,
  "factors": [3.14, 2.71, 1.618],
  "config": {
    "threshold": 0.05,
    "period": 20
  }
}
```

### 前端TypeScript接口定义
```typescript
interface StockData {
  tradeDay: string;
  stockCode: string;
  price: number;
  volume: number;
  isTrading: boolean;
  factors: number[];
  config: {
    threshold: number;
    period: number;
  };
}
```
