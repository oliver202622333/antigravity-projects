常见问题

以下是关于掘金下单的常见问题解答，如未找到答案，请联系技术支持。

掘金下单

1. 如何开通掘金下单功能？

开通掘金下单功能需要以下步骤：

  1. 完成账户实名认证
  2. 签署相关风险揭示书
  3. 完成适当性评估
  4. 联系客户经理或在线申请开通
提示
开通后需要在客户端重启才能生效。
2. 支持哪些交易品种？

目前掘金下单支持以下交易品种：

  • A股（主板、创业板、科创板）
  • 场内基金（ETF、LOF）
  • 可转债
  • 国债逆回购

港股通和期货品种正在开发中，敬请期待。

3. 下单有什么限制？

下单限制如下：

品种 单笔最小 单笔最大 备注
A股 100股 100万股 100股整数倍
基金 100份 100万份 100份整数倍
可转债 10张 10万张 10张整数倍
4. 如何使用 API 下单？

使用 API 下单的基本示例：

# Python 示例
from gm.api import *

# 初始化
set_token("your_token_here")

# 下单
order_volume(
    symbol='SHSE.600000',
    volume=100,
    side=OrderSide_Buy,
    order_type=OrderType_Limit,
    price=10.50
)

详细 API 文档请参考 API 参考。

5. 订单状态有哪些？

订单状态说明：

  • 已报 - 订单已提交，等待撮合
  • 部成 - 部分成交
  • 已成 - 全部成交
  • 部撤 - 部分成交后撤单
  • 已撤 - 已撤单
  • 废单 - 订单无效
6. 交易时间是什么时候？

A股交易时间：

  • 上午：9:30 - 11:30
  • 下午：13:00 - 15:00
  • 集合竞价：9:15 - 9:25
  • 创业板/科创板盘后定价：15:05 - 15:30

国债逆回购交易时间延长至 15:30。

7. 如何撤销订单？

撤单操作示例：

# 撤销指定订单
cancel_order(cl_ord_id='your_order_id')

# 撤销账户所有未成交订单
cancel_all_account_orders(account_id='your_account_id')
注意
已成订单无法撤销，部分成交订单只能撤销未成交部分。
8. 手续费怎么计算？

A股交易费用包括：

  • 佣金：不超过成交金额的 0.3%，起点 5 元
  • 印花税：成交金额的 0.1%（仅卖出收取）
  • 过户费：成交金额的 0.001%（仅沪市收取）
  • 经手费、证管费：包含在佣金中

具体费率以账户签约为准。
